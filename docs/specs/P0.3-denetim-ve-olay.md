## audit_log

Sütunlar: `id, table_name, record_id, action(audit_action), actor_id, actor_email,
changed_fields text[], old_values jsonb, new_values jsonb, source(audit_source),
ip_address inet, user_agent text, created_at`.
İndeksler: `(table_name, record_id)`, `(actor_id)`, `(created_at desc)`.

- RLS: yalnızca `audit_log_select` (aktif kullanıcı okur). Insert/update/delete
  politikası YOK.
- Trigger: `audit_log_no_update`, `audit_log_no_delete` (row), `audit_log_no_truncate`
  (statement) → `prevent_mutation()`.
- Grant: `select` → authenticated; `revoke all` → anon.

## Fonksiyonlar

- `audit_trigger()` — jenerik, SECURITY DEFINER `search_path=''`. Maskeleme,
  soft-delete/restore ayrımı, changed_fields (updated_at hariç), actor auth.users'tan,
  source GUC/oturum, ip/ua request.headers'tan.
- `prevent_mutation()` — append-only tablolar için update/delete/truncate engeli.
- `log_event(type, entity_type, entity_id, payload) → bigint` — SECURITY DEFINER,
  actor_id = auth.uid().

## event_log

Sütunlar: `id, event_type, entity_type, entity_id, actor_id, payload jsonb, created_at`.
İndeksler: `(entity_type, entity_id)`, `(event_type)`, `(created_at desc)`.
- RLS: `event_log_select` + `event_log_insert` (aktif kullanıcı).
- Trigger: `event_log_no_truncate` (statement).
- Grant: `select, insert` → authenticated; `revoke all` → anon.
