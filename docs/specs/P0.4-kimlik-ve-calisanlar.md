## Tablolar

- **departments**: `id, name, code(unique), description, sort_order, is_active, ts`.
- **positions**: `id, department_id(→departments, restrict), name, code, is_active, ts`.
  Kısmi unique: `(department_id, code) where department_id is not null` +
  `(code) where department_id is null`.
- **users**: `id(uuid, →auth.users restrict), email(unique), full_name, phone,
  department_id, position_id, role_id(FK P0.5), is_active, must_change_password,
  last_login_at, avatar_file_id(FK P0.7), created_by, deleted_at, deleted_by, ts`.
  İndeksler: department, position, role, `(is_active) where deleted_at is null`.

## Frontend kontratı (P0.9–P0.10'da bağlanacak)

Yönetici çalışan ekleme: `supabase.functions.invoke('create-user', { body: { email,
password, full_name, role_id?, department_id?, position_id?, phone? } })`.
Şifre sıfırlama: `invoke('reset-user-password', { body: { user_id, new_password } })`.
Pasifleştirme: `invoke('set-user-active', { body: { user_id, is_active } })`.
Kullanıcının kendi şifresini e-posta ile sıfırlaması: `supabase.auth.resetPasswordForEmail`
(service_role gerekmez, frontend'de).
