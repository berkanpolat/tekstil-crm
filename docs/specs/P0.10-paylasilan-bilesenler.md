# P0.10 — Paylaşılan Bileşenler · Spec (Ne yapıldı)

Sistemin her yerinde kullanılacak bileşenler. Tutarlılık burada kazanılır: bir
bileşen her modülde aynı davranır → kullanıcı yeniden öğrenmez.

## Bileşenler (`src/components/shared/`)

| Bileşen | Özet |
|---|---|
| `DataTable` | Sunucu tarafı sayfalama/sıralama, kolon gizleme, satır seçimi, yükleniyor iskeleti, boş durum. Yalnızca geçerli sayfa render → 100k satırda hızlı. 64px iki-satırlı satır destekli. |
| `SearchableSelect` | **Aranabilir tekil seçim — her açılır menü bunu kullanır** (CEO talebi). Popover + cmdk, TR-duyarlı arama, klavye erişilebilir. |
| `StatusBadge` | Durum anahtarı → etiket + renk (`src/lib/statuses.ts` kaydından). Renkler tek yerden. |
| `PageHeader` | Başlık, açıklama, birincil aksiyon, geri butonu. |
| `FilterBar` | Arama kutusu + filtre alanları (children) + "filtreleri temizle". |
| `EmptyState` | İkon + metin + yönlendirici aksiyon. |
| `ConfirmDialog` | Yıkıcı işlem onayı; sonucu açıkça yazar; busy durumu. |
| `Timeline` | Kronolojik olay akışı (ton renkleri + ikon). |
| `DateRangePicker` | Hazır aralıklar (bugün/bu hafta/bu ay) + özel takvim (2 ay, TR locale). |
| `FormField` | Etiket + yardım + hata + zorunluluk (`*`) — tek sarmalayıcı, id otomatik bağlı. |
| `FileUpload`/`FileList` | P0.7'de yazıldı (drag-drop, imzalı URL, sürüm, soft-delete). |

## Destek

- `src/lib/statuses.ts` — durum kaydı (key → label + tone) + tone→token sınıf eşlemesi.
- shadcn primitive'leri eklendi: input, label, select, popover, command, dialog,
  table, checkbox, badge, skeleton, calendar (+ P0.9'dakiler).

## Yazı / davranış kuralları

- Buton fiili ne yapacağını söyler ("Çalışan ekle").
- Aynı işlem her yerde aynı isim.
- Hata mesajı ne olduğunu + nasıl düzeltileceğini söyler (özür dilemez).
- Yükleme: spinner değil **iskelet** (DataTable).
- Odak halkası turuncu; klavye ile gezilebilir.
