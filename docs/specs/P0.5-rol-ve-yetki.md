## Tablolar

- **roles**: `id, key(unique), name, description, is_system, is_active, ts`.
- **permissions**: `id, key(unique=module.action), module, action, description, created_at`.
- **role_permissions**: `(role_id, permission_id)` PK, FK'ler `on delete cascade`.
- **user_permission_overrides**: `id, user_id, permission_id, granted, granted_by,
  reason, expires_at, created_at` + user/expiry indeksleri.

## Tohumlar

- 7 rol: owner, admin (is_system=true); manager, sales, operations, finance, viewer.
- 13 yetki (users.*, roles.*, departments.*, positions.*, settings.*).
- admin → 12 role_permission (roles.manage HARİÇ; onu yalnızca owner yönetir).

## Fonksiyonlar

- `has_permission(text)` — GERÇEK: aktif → owner short-circuit → override(süreli) →
  role_permissions.
- `is_admin_or_owner()` — RLS yazma politikaları için.
- `guard_user_permission_override()` — (A) self override yasak, (B) sahip olmadığın
  yetkiyi granted=true veremezsin; owner/sistem muaf.
- `guard_role_permission()` — sahip olmadığın yetkiyi role ekleyemezsin; owner/sistem muaf.
- `prevent_system_role_delete()` / `guard_system_role_update()` — sistem rolü
  silinemez; key/is_system değişmez.
- `handle_new_user()` — sağlamlaştırıldı (owner rolü yoksa exception).

## Bootstrap

- Backfill: null role_id'li en eski kullanıcıya owner (owner yoksa).
- `users_role_id_fkey` → roles(id) `on delete restrict` (backfill'den sonra).

## RLS

Dört tablo: select = `is_active_user()`; write (`for all`) = `is_admin_or_owner()`.
`revoke all from anon`; `grant select,insert,update,delete ... to authenticated`.

permissions/role_permissions/user_permission_overrides: audit.
role_permissions: guard (insert/update). user_permission_overrides: guard (ins/upd/del).
