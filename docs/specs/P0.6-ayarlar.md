# P0.6 — Ayarlar Altyapısı · Spec (Ne yapıldı)

## Migration

`supabase/migrations/20260725150000_p0_6_settings.sql`

## Tablolar

- **settings**: `key(PK), value(jsonb), category, description, is_sensitive,
  updated_by, updated_at`.
- **setting_history**: `id, setting_key, old_value, new_value, changed_by, changed_at`
  (+ `(setting_key, changed_at desc)` indeksi). Append-only.

## Trigger'lar / fonksiyonlar

- `settings_stamp` (BEFORE UPDATE): `updated_at=now()`, `updated_by=auth.uid()`.
- `settings_write_history` (AFTER UPDATE): değer değiştiyse geçmişe yaz; is_sensitive
  ise değer `"***"`.
- `settings_prevent_delete` (BEFORE DELETE): ayar silinemez.
- `settings_insert_system_only` (BEFORE INSERT): auth.uid() varsa red (yalnızca migration).
- setting_history: `prevent_mutation` ile update/delete/truncate engelli.

## RLS

- settings select: `is_active_user() and (not is_sensitive or is_admin_or_owner())`.
- settings update: `is_admin_or_owner()` (insert/delete trigger ile kapalı).
- setting_history select: aktif kullanıcı; hassas anahtarların geçmişi owner/admin'e kısıtlı.
- `revoke all from anon`; `grant select, update on settings`, `grant select on
  setting_history` to authenticated.
